🎱 Random Answer API

Created by: dittxz

Base URL: https://maeshito.vercel.app

📌 Overview

This API answers any yes/no/maybe style question randomly, just like Magic Clam from SpongeBob. Supports Indonesian and English only.

🔗 Endpoint

GET https://maeshito.vercel.app/rA

📝 Query Parameters

Param Type Required Description Values
q String ✅ Yes Your question text Any text / question
lang String ❌ No Answer language
Default = en		 id = Indonesian
en = English

💬 Possible Answers

🇮🇩 Indonesian (lang=id): Ya, Mungkin, Enggak

🇺🇸 English (lang=en): Yes, Maybe, No

🚀 Example Requests

▶ Indonesian

GET https://maeshito.vercel.app/rA?q=AmIGettingAGirlFriends?&lang=id

Response:

{
  "creator": "dittxz",
  "question": "AmIGettingAGirlFriends?",
  "language": "id",
  "answer": "Mungkin"
}

▶ English

GET https://maeshito.vercel.app/rA?q=WillItRainToday&lang=en

Response:

{
  "creator": "dittxz",
  "question": "WillItRainToday",
  "language": "en",
  "answer": "Yes"
}
